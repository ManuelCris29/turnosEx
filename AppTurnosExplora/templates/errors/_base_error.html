POR QUÉ ES AUTOCONTENIDA (no hereda de base.html y no carga NADA externo): 1. SEGURIDAD. Con DEBUG=False estas páginas sustituyen a las pantallas técnicas de Django, que filtran el URLconf completo, el traceback y los settings. Aquí no se muestra ningún dato interno: ni ruta solicitada, ni excepción, ni nombres de vista. Lo único que viaja al usuario es un código de referencia opaco que el equipo de desarrollo puede cruzar contra el log (fichero + CloudWatch). 2. ROBUSTEZ. handler500 se ejecuta cuando algo YA ha fallado. Si esta plantilla heredara de base.html renderizaría el sidebar completo, que consulta `user.empleado.notificaciones_no_leidas_count` — es decir, tocaría la base de datos que probablemente es la que se ha caído, y el error 500 se convertiría en un 500 desnudo de Django. Además Django renderiza handler500 con un contexto VACÍO: no hay `request`, ni `user`, ni context processors. Por eso aquí no se usa ninguna variable de contexto obligatoria y no hay etiquetas {% templatetag openblock %} url {% templatetag closeblock %}: los enlaces son rutas literales. 3. DISPONIBILIDAD. Todo el CSS y el SVG van en línea. Si S3/WhiteNoise o la red de estáticos fallan, la página sigue viéndose perfecta.
