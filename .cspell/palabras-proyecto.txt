# Diccionario del proyecto AppTurnos / SWALP
#
# Una palabra por linea. Lo que hay aqui NO lo marca el corrector.
#
# Por que existe: el diccionario espanol de cSpell (@cspell/dict-es-es) cubre
# el espanol bien escrito, pero este codigo esta lleno de tres cosas que ese
# diccionario no tiene y que aqui son correctas:
#
#   1. Espanol SIN TILDE. Los identificadores no admiten acentos, asi que el
#      codigo dice `anio`, `dias`, `cesion`, `sabado`, `notificacion`.
#   2. Imperativos con pronombre pegado: `apruebala`, `recházalo`, `quítaselo`.
#   3. Jerga tecnica castellanizada: `parsear`, `loguear`, `renderizar`,
#      `reaplicar`, `reprogramar`, `commitear`.
#
# Tambien van aqui los nombres propios de personas y lugares que aparecen en
# datos de prueba y comentarios.
#
# Y un cuarto grupo, que no son palabras: fragmentos que cSpell inventa al
# partir el texto. Trocea los identificadores compuestos (`es_dfds` -> `dfds`,
# `codigo_estrategia` -> `strat`) y corta las palabras en la tilde
# (`unicamente` -> `nicamente`, `despues` -> `despu`). No hay nada que
# corregir en el codigo: es como el corrector lee, no como esta escrito.
#
# Lista generada a partir del corpus real del proyecto (todas las palabras que
# quedaban marcadas tras activar el diccionario espanol) y revisada una a una:
# no habia ni una errata de verdad.
#
# Para anadir una palabra: escribela aqui, o usa "Add to project dictionary"
# desde la bombilla de VSCode, que la anade a este archivo.
